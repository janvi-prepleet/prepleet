# PrepLeet

Next.js and Supabase MVP: Google sign-in, guesstimate guides, sample PDF downloads and comments. Practice is coming soon.

Use Node.js 24. Run `npm ci`, copy `.env.example` to root `.env` if needed, then `npm run dev`.

Checks: `npm run typecheck`, `npm test`, `npm run test:integration`, and `npm run test:db` (Docker).

See [setup](docs/SETUP.md), [deployment](docs/DEPLOYMENT.md), and [the plan](docs/PLAN.md).
